# Vintage Barbershop Website

A responsive, interactive barbershop website concept built with **HTML, CSS, and JavaScript**. This project was designed to demonstrate front-end development, responsive UI design, accessibility considerations, and interactive user experiences.

> **Note:** Vintage Barbershop is a fictional business created as a portfolio project. The appointment system is an interactive front-end prototype and does not process real bookings.

## 🌐 Live Demo

**[View the Live Website](https://shvatz009.github.io/Barbershop-Website/)**

## 📋 Project Overview

The Vintage Barbershop project was created to simulate a real-world business website from the perspective of both a user and a front-end developer.

The goal was to create a polished, responsive website that allows visitors to:

* Learn about the barbershop and its services
* Browse available haircut and grooming services
* View service details and pricing
* Explore business hours
* Select an appointment date
* Choose from available appointment times
* Submit an appointment request through an interactive interface
* Access contact information
* Navigate the site comfortably across desktop and mobile devices

## ✨ Key Features

### Responsive Design

The website was designed to adapt to different screen sizes, including:

* Desktop computers
* Tablets
* Mobile phones

Responsive layouts, flexible components, and mobile navigation help provide a consistent experience across devices.

### Interactive Appointment Booking

The booking interface includes:

* Dynamic calendar generation
* Current-date awareness
* Disabled past dates
* Business-hour restrictions
* Available appointment time slots
* Date and time validation
* Booking confirmation feedback

The appointment system is intentionally implemented as a **front-end prototype** and does not connect to a backend or process real appointments.

### Dynamic Service Content

Services are stored as JavaScript objects and dynamically rendered onto the page.

Current services include:

* Classic Haircut
* Beard Trim
* Straight Razor Shave
* Children's Haircuts
* Fade and Style

Each service includes information such as pricing, descriptions, images, and additional details.

### Interactive Modals

The website uses modal interfaces for:

* Service details
* Contact/call information

The modal system includes keyboard-friendly behaviors such as:

* Escape-key closing
* Focus management
* Focus restoration
* Background scroll prevention
* Appropriate `aria-hidden` states

### Mobile Navigation

A responsive mobile navigation menu provides access to the site's primary sections while maintaining the desktop navigation experience.

### Form Validation

The appointment interface validates required information before allowing a booking request to proceed.

### Accessibility Considerations

Accessibility was considered throughout the development process, including:

* Semantic HTML
* Form labels
* ARIA attributes
* Keyboard interaction
* Focus management
* Live regions for dynamic messages
* Accessible navigation controls
* Responsive layouts

Accessibility remains an ongoing area for improvement as the project develops.
